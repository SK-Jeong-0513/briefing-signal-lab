## 1. 왜 하는가

대시보드가 미국 편중이다. 미국은 FRED 로 금리·통화량·준비금이 촘촘한데,
한국은 야후에서 긁을 수 있는 **가격만** 있다.

| 영역 | 현재 커버리지 |
|---|---|
| 미국 | 지수 5 · 금리 2/5/10Y · M2 · 은행준비금 · TGA · 원자재 4 · 섹터 ETF 11 |
| 한국 | KOSPI · 원/달러 · EWY · 삼성전자 · 거래량 · 관세청 수출 — **매크로 0** |

한국 기준금리도, 국고채 커브도, CPI 도, 경상수지도 없다. ECOS 가 이 구멍을 메운다.

## 2. 확정 설계

### 2-A. 관계 페어 1개 (일간)

```
좌축  한미 10년 금리차 = 국고채(10년) − 미 10년물        [파생 시리즈]
우축  KOSPI                                          [기본값]
드롭다운  KOSPI · 외국인 순매수(유가증권) · KOSDAQ        [전부 ECOS 802Y001]
```

**만기를 맞춘 이유.** 한국 벤치마크는 국고 3년이고 미국은 2년·10년이라 조합이 갈린다.
10년−10년은 만기가 정확히 대응해 기간프리미엄이 섞이지 않고, 외국인 채권자금·환율과의
관계가 가장 잘 알려져 있다. 히스토리도 깊다(국고 10년 2000-12-18~, DGS10 훨씬 김).

**우축을 KOSPI 로 둔 근거는 실측이다**(§3-C). 원/달러보다 금리차와 강하게 붙고,
기존 `dollar-kospi` 페어와 겹치지도 않는다.

⚠️ **드롭다운 옵션은 전부 ECOS `802Y001` 에서 받는다.** `fetch_dashboard.py:56` 이
"한 페어 안에서는 소스를 섞지 말 것 — 드롭다운을 바꿀 때마다 차트 끝 날짜가 달라진다"
고 정하고 있다. 세 옵션이 같은 표·같은 거래일 달력이면 이 규칙을 우회가 아니라 정면으로
만족한다. **KOSPI 를 야후 `ks11` 로 두면 안 된다** — 드롭다운 안에서 소스가 섞인다.

> 규칙의 범위에 대한 메모: 이 규칙은 **드롭다운 안**을 말한다. 좌우축이 서로 다른
> 소스인 것은 기존 페어도 그렇다(`tga-index` 미 재무부+야후, `m2-index` FRED+야후,
> `wti-rates` 야후+FRED). 그래서 좌축 FRED·우축 ECOS 자체는 문제가 아니다.

### 2-B. 카드 11장 (월간)

기존 `vcCard()` 를 재사용한다 — 밸류체인·섹터가 이미 같은 함수를 쓰고,
**`period` 인자를 이미 받는다**(`dashboard.js:97`).

| 묶음 | 카드 | 표시 기준 |
|---|---|---|
| 심리 | 소비자심리(CSI) · 기업심리(BSI) · 경제심리(ESI) | **100 기준선 대비 포인트 차** |
| 물가 | 소비자물가지수 · 근원(농산물·석유류 제외) | **전년동월비** |
| 증시 자금 | 외환보유액 · 경상수지 · (투자자예탁금은 §5 참조) | **전월비** |
| 실물 경기 | 선행지수순환변동치 · 전산업생산 · 소매판매 | **전년동월비** |

**신선도 충돌은 형태로 푼다.** 기존 기준(`fetch_dashboard.py:52-56`)은 *차트* 오른쪽이
비는 걸 막으려던 것이고, 실제로 M2SL·TOTRESNS 가 "월별 + 발표지연 78일" 로 탈락한 전례가
있다. 월간 지표를 **차트가 아니라 카드 + `2026.08 기준` 라벨**로 내면 그 문제 자체가 없다.
섹터 카드가 이미 90개만 읽는 것과 같은 패턴이다.

### 2-C. 표시 기준을 지표별로 두는 이유

지표 유형마다 의미 있는 숫자가 다르다. 통일하면 어느 한쪽이 오독된다.

- **CPI 전월비 `+0.2%`** 는 한국 독자가 기대하는 숫자가 아니다. 전년동월비로 읽는다.
- **심리지수는 변화율이 아니라 100 기준선 대비 위치**가 핵심이다.
  `104.5 (+1.2%)` 보다 `104.5 · 기준선 +4.5` 가 정보다.
- **예탁금·외환보유액·경상수지**는 전월비가 자연스럽다.

시리즈 정의에 `mode` 필드를 두고 `vcCard()` 가 그걸 읽게 한다.

### 3-B. 한미 10년 정렬 (2025-01-01 ~ 2026-09-06)

```
KR 거래일 409 · US 거래일 419 · 교집합 395  → 94.3% 보존
미 휴장(KR만) 14일 · 한 휴장(US만) 24일
최대 공백 8일 (2025-10-02 → 10-10, 추석)
스프레드 범위 −1.94 ~ −0.15 %p   최신 2026-09-03 −0.40 %p
```

**교집합(inner join)만 쓴다. forward-fill 하지 않는다** — 94.3% 가 남고, 결측 보간은
없는 데이터를 지어내는 쪽이다. uPlot 이 8일 공백은 선으로 잇는다.
스프레드 최신일은 **둘 중 느린 쪽(미국)에 맞춰 D-3** 가 된다.

## 5. ⚠️ 함정 — 착수 전에 반드시 읽을 것

### A. `pctChg` 가 월간 데이터에서 조용히 틀린다

`dashboard.js:31`:

```js
function pctChg(v) { var back = v[Math.max(0, v.length - 22)]; ... }
```

`-22` 는 **거래일 22일 ≈ 1개월**을 노린 값이다(섹터 카드는 일간 주가라 맞다).
월간 시리즈에 그대로 쓰면 **22개월 전 대비**가 계산되고, 라벨은
`per = period || "~1M"` 이라 **"~1M" 으로 표시된다**.
CPI 처럼 단조 상승하는 지표면 `+18.3% ~1M` 이 찍혀도 아무도 이상하게 보지 않는다.

### B. `manual` 플래그가 두 일을 겸하고 있다

`dashboard.js:97`:

```js
var chg = (manual && v.length >= 2) ? (v[len-1]/v[len-2] - 1)*100 : pctChg(v);
```

`manual=true` 는 **직전 대비 계산**과 **`<span class="vc-tag">수동</span>` 배지**를
동시에 켠다. 월간 지표는 앞은 필요하고 뒤는 틀리다(수동 입력이 아니다).
**플래그를 분리해야 한다** — §2-C 의 `mode` 필드가 그 자리다.

### C. 투자자예탁금은 일간이 아니다

`802Y001`(주식시장, 일간)에 예탁금은 없다. 100대 지표에는 월간(202608)으로 나온다.
대신 **외국인 순매수가 일간**이라 전달 경로를 더 잘 보여준다 — §2-A 드롭다운에 넣었다.
예탁금을 카드로 쓰려면 표를 따로 찾아야 한다.

### D. `.env` 파싱 시 주석을 자를 것

`BoKorea/.env` 는 `API_KEY=... # 주석` 형태다. `split("=",1)[1]` 만 하면 주석이 딸려와
URL 에 공백이 들어가고 요청이 깨진다. `re.split(r'[#\s]', v.strip())[0]` 로 자른다.

> 2026-09-06 에 이 실수로 오류 메시지에 키 값이 노출됐다. **재발급 권장.**

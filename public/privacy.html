개인정보처리방침

시행일 2026-09-14

Briefing Signal Lab(이하 '서비스')은 개인 운영자가 운영하는 무료 브리핑 구독 서비스입니다. 이 방침은 서비스가 어떤 정보를 어떤 목적으로 수집·보관·이용하는지, 이용자가 어떤 권리를 갖는지 설명합니다.

1. 수집하는 정보와 목적

구독 신청

  • 항목 — 이메일 주소, 메일 수신 동의 여부. Google Forms 로 신청하는 경우 관심 키워드(선택)를 함께 받습니다.
  • 목적 — 일일 시황·주간 브리핑·스페셜 리포트 메일 발송, 수신거부와 재구독 처리.
  • 방법 — 사이트의 구독 폼 또는 Google Forms 에 이용자가 직접 입력합니다.

방문 기록

  • 항목 — 방문 일시, 방문한 페이지 경로, 유입 경로(referrer), 익명 방문자 ID.
  • 익명 방문자 ID는 브라우저의 localStorage 에 저장되는 임의 문자열입니다. 이름·이메일·IP 주소처럼 이용자를 식별할 수 있는 정보와 연결되지 않으며, 브라우저 저장소를 지우면 초기화됩니다. 서비스는 쿠키를 사용하지 않습니다.
  • 목적 — 방문 수와 유입 경로를 대략 파악해 서비스를 개선합니다.

문의 메일

이메일로 문의하시면 발신 주소와 문의 내용이 답변 목적으로 보관됩니다.

2. 보관 기간

  • 구독 정보 — 구독을 유지하는 동안 보관합니다. 수신거부하면 발송 대상에서 제외되며, 정보의 삭제를 원하시면 아래 연락처로 요청해 주세요. 지체 없이 삭제합니다.
  • 방문 기록 — 통계 목적으로 보관하며 개인을 식별할 수 있는 정보를 포함하지 않습니다.
  • 문의 메일 — 답변이 끝난 뒤 보관할 이유가 없으면 삭제합니다.

3. 외부 서비스

서비스는 아래 외부 서비스를 이용하며, 그 과정에서 정보가 해당 서비스의 서버에 전송·저장됩니다.

  • Google (Forms · Sheets · Apps Script · Gmail) — 구독 정보 저장, 브리핑 메일 발송, 방문 기록 저장.
  • GitHub Pages — 웹사이트 호스팅. 페이지를 요청하면 IP 주소 등 접속 정보가 GitHub 의 서버 로그에 남을 수 있습니다.
  • Google Fonts · jsDelivr — 웹폰트와 스크립트 제공. 파일을 요청하면 IP 주소가 해당 서비스에 전달될 수 있습니다.
  • Google Sheets 게시 데이터 — 브리핑·시황 본문을 불러올 때 브라우저가 docs.google.com 에 직접 요청합니다.

서비스는 이 외의 제3자에게 개인정보를 제공하거나 판매하지 않습니다.

4. 광고

현재 서비스는 제3자 광고를 게재하지 않으며, 광고 목적의 쿠키나 추적 기술을 사용하지 않습니다. 향후 광고를 도입하는 경우 이 방침을 갱신하고, 광고 제공자와 쿠키 사용 내용을 이 항목에 명시한 뒤 적용합니다.

5. 이용자의 권리

  • 수신거부 — 모든 브리핑 메일 하단의 '구독 취소' 버튼을 누르면 확인 페이지가 열립니다. 그 페이지에서 해지를 확정하면 즉시 발송 대상에서 제외됩니다. 링크를 여는 것만으로는 해지되지 않습니다(오클릭 방지).
  • 재구독 — 사이트의 구독 폼으로 다시 신청하면 됩니다.
  • 열람·정정·삭제 — 아래 연락처로 요청하시면 본인 확인 후 처리합니다.

6. 안전조치

구독 정보는 운영자 계정에서만 접근할 수 있는 Google 스프레드시트에 보관합니다. 메일의 수신거부 링크는 이메일 주소를 그대로 담지 않고 해시 토큰을 사용합니다.

7. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
